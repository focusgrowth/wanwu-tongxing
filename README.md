# 万物同形

雨亭文化工作室出品的一本互动自然图鉴。

## 为什么做这个网站

我最初想做《万物同形》，是因为看到了一个数学公式。用每转一圈的半径倍率来写，它是这样的：

$$r(θ)=r_0 W^{θ/(2π)}$$

把它读成一句话，就是每转一圈，半径乘上同一个数。取 W = 2，沿着同一条射线依次数过去，半径就是 1、2、4、8。只改一个数，眼前的螺旋就换了一副模样。我觉得这太美妙了。

我又想起蜗牛壳和羊角。把它们放在一起，眼睛会顺着相似的弧线走。它们到底从哪里开始相像，又在哪里分开？这个问题成了网站的第一页。这里的曲线供观察和比较，标本轮廓还没有逐一测量拟合。

## 你可以从哪里逛起

打开形状实验室，拖动滑杆，看看每一圈怎样展开。再把蜗牛和鹦鹉螺并排放在形状对照区，试着找出照片里哪些细节无法用一条线描述。生物图鉴已有 34 个代表条目，现生软体动物八纲都有入口，可以沿分类名录继续往下查。

## 一起完善它

欢迎通过 Issue 提问或提交资料，也欢迎直接发起 Pull Request。

- **补标本**：选一条缺图的记录，附学名、原图地址、摄影者、许可与拍摄视角。能看清壳口或铰合部的照片尤其有用。
- **补地方饮食**：附当地名称、流传地区和可核对的出处。如果知道食材来自哪里，也请单列。
- **纠错**：写明条目名称、原句、建议改法和依据。只发现疑点也欢迎提出。

可以先从「象牙贝」入手，为它找一张能看清两端开口的授权照片。

## 本地预览

在仓库根目录运行：

```sh
python -m http.server 8000 --directory dist
```

浏览器打开 http://localhost:8000 。无需安装前端依赖。图鉴数据位于 dist/catalog.js，学名查询需要联网。
